# HITSVILLE USA Recording Studio

**SNA-CLAW-3270 Session Recorder + Smart INI Builder**

> "Where the hits are recorded" — The easiest way to create reliable 3270 automation skills.

---

## Overview

Hitsville USA is a **full interactive recording studio** for SNA-CLAW-3270.  
Instead of manually writing complex `.ini` files, users simply **perform their normal workflow** in a real 3270 terminal. The studio records at the intelligent **field/action level** and generates production-ready skills automatically.

### Key Features
- Full interactive 3270 terminal experience (`tnz.zti`)
- Intelligent screen aliasing with user-friendly names
- Automatic step detection + manual naming
- Full support for PF, PA, ATTN, CLEAR keys
- Pause/Resume and Partial Save (session interrupt friendly)
- Beautiful HTML visual recording reports
- Clean, well-commented `.ini` output
